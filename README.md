# 三人谁是卧底发牌器

一个适合手机传阅的纯前端小游戏。无需登录或主持人，三名玩家依次查看词语，线下讨论投票后在页面内揭晓结果。

## 功能

- 固定三人局：两名平民、一名卧底
- 综合随机或按动画、校园、生活、自然、食物、运动分类抽取
- 132 组小学生熟悉的词语，自动避开最近抽过的 20 组
- 使用浏览器安全随机数随机卧底位置、词语归属和词组
- 一轮投票后展示胜负与完整底牌
- 纯 HTML、CSS、JavaScript，可直接部署到 GitHub Pages
